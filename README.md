# NZXT — Sistema Integral de Logística

Aplicación de escritorio para Windows orientada a la logística integral de una empresa informática.

## Estado

El proyecto está en preparación. La solución se desarrollará con Electron, React y TypeScript, usando `localStorage` para la persistencia local y sin base de datos externa.

## Alcance previsto

- Dashboard y indicadores
- Inventario y almacén
- Compras y proveedores
- Ventas y clientes
- Transporte y entregas
- Soporte técnico y garantías
- Usuarios y permisos
- Reportes, PDF e impresión
- Importación y exportación de respaldos
